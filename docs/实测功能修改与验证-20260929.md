# 实测功能修改与验证

## 修改内容

- 统一入口仍为 `POST /api/v1/fluxcast/compute`，请求字段不变，不增加对外容器或端口。
- 全天预测按北京时间自然日保存96点，同日首次成功且曲线就绪时返回；后续新断面不重复返回整批，原发布请求重试除外。
- 每次继续接收35个测点的96帧历史，但已有对应日期曲线后不再执行当天模型推理。跨日准备下一日曲线，缺少曲线时按原规则补算。
- 从末帧19个原始功率测点计算totalPowerActual；同UTC时刻且事先生成的已发布全天预测可用时，计算totalPowerDeviation（预测减实测，MW）。
- 首次现算当天曲线时，也允许返回首次发布请求当前一点的偏差，extra_info标记deviationBasis=initial_curve_comparison。仅限原补算路径、零点前历史、同UTC目标和同一已发布批次；不改生成时间、不回填其他历史偏差、不改写已保存响应。
- 缺测不补成实测值，使用extra_info报告状态；无对应预测只返回实测，不伪造偏差。联合请求失败仍沿用原错误响应。
- 全天基础镜像替换为ba6d7d35b873版本，并更新Dockerfile、Compose环境示例及镜像身份清单。最终联合镜像标签改为20260929-observations，避免与原r5混淆。

核心新增文件为 `src/actual_power.py`、`src/day_forecast_runtime.py`；联合调用与每日保存分别在 `api.py`、`src/day_forecast_publication.py`。输入输出及部署要求见[接口说明](实测合计与全天预测偏差.md)。

15分钟模型镜像、调度核心、原始业务数据和独立生产部署包未修改，未重新训练模型。
